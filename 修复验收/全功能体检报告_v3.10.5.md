# 统一工具箱 · 全功能 BUG 体检报告（v3.10.5）

> 体检范围：弹窗完整性、敏感数据安全、删除/清理安全、线程安全/异常、残留扫描、实用工具模块。
> 结论：**未发现高危 BUG；修复 5 处线程安全/健壮性问题（已落盘，待发版）。**

## 一、弹窗完整性（用户重点①）

全库所有交互弹窗均走自定义暗色对话框 `_dark_dialog`（约 2883 行），**无任何 `tkinter.messagebox` 原生弹窗**。

- 按钮统一置底（`btnf` 在底部 pack），长消息不会被挤出按钮；
- 三个关闭通道均有归属：Enter（确认）/ Esc（取消）/ 窗口 X（`WM_DELETE_WINDOW`）——不会"关不掉"；
- 模态弹窗均 `grab_set` + 居中于父窗口，焦点不丢失；
- 确认类弹窗覆盖：清理 / 卸载 / 删除 / 激活 / 升级 / 残留 / 启动项 / 还原点 / 定时任务，全部带 `danger=True` 红色警示样式。

**结论：所有弹窗都有按钮，无"无按钮死角"。**

## 二、删除 / 清理安全（用户重点③）

### 2.1 删除路径分级保护

| 调用点 | 做法 | 风险 |
|---|---|---|
| 9 处常规删除（111/332/405/1486/1506/2468/4353/4480/5384） | 仅删本程序自身临时文件 / 自有缓存 / 白名单文件 | 低 |
| 用户文件删除（7251 等） | `delete_to_recycle_bin()` → 回收站（SHFileOperationW + FOF_ALLOWUNDO）**可还原** | 低 |
| 空间清理 `_delete_clean_jobs`（5369） | 多级白名单 + 逐级 `lstat` 防 junction + home 祖先保护 + **1 小时活跃豁免** + 任务白名单二次校验 | 低 |
| 残留清理 `_delete_selected`（6588） | 仅删"有归属证据的安装目录" + 删除前重新 `_owned_residual_dir` 校验 + 回收站 | 低 |
| **注册表删除 `_reg_delete_tree`（5658）** | **无任何外部调用点（仅自递归）→ 死代码，实际不可达** | 无（功能已禁用） |

### 2.2 关键发现：注册表删除已被安全禁用
- `_scan_residuals`（6503）只返回"有归属证据的安装目录"，**从不返回注册表键**；
- `_residual_dialog._delete_selected`（6613）对注册表行显式 `r_fail += 1`（注释：No verified registry ownership/backup）；
- 因此 `_reg_delete_tree` 虽存在但**不可达**，残留清理不会动注册表。

## 四、线程安全 / 异常（修复 5 处）

统一工具箱为 Tk 单线程模型，后台 daemon 线程误调 Tk 控件会偶发 `RuntimeError: main thread is not in main loop`。本次修复：

| # | 位置 | 问题 | 修复 |
|---|---|---|---|
| 1 | `_uwp_dialog._do_scan`（~6692） | 后台线程内 `top.after(0, _fill)` 跨线程 Tk 调用 | 改为主线程 `scan_res` 字典 + `scan_seq` 防串台 + `_poll` 轮询回填 |
| 2 | `_uwp_dialog._remove_selected`（~6740） | 主线程 for 循环 `subprocess.run(timeout=120)` 卸载 N 个包，最长卡 UI N×120s | 改 daemon 线程 + `queue.Queue` 进度回传 + 按钮 `state="disabled"` 防重入 |
| 3 | `_build_index`（~8470） | 后台线程 `win.winfo_exists()`/`info.config` 跨线程 Tk 调用 | 置 `state["save_error"]`，主线程 `_tick` 渲染 |
| 4 | `_activation_command`（7797） | `subprocess.run` 无 timeout，用户不理 UAC 时线程永久挂起、按钮永久禁用 | 加 `timeout=900` + `TimeoutExpired` 友好提示 |
| 5 | `show_warning` 调用（~8519） | `show_warning(self.root, "打开失败", ...)` 把 root 当 title，参数错位 | 改为 `show_warning("打开失败", "无法调起资源管理器", parent=self.root)` |

## 五、残留扫描（用户重点③延伸）

- `_scan_residuals` 仅提供"应用专属安装目录"且需 `_owned_residual_dir` 归属证明；
- 不确定目录与注册表删除**已禁用**（见 2.2）；
- 删除前有 `ask_yesno(danger=True)` 确认，且删除前重新校验归属 → **不会误删**。
